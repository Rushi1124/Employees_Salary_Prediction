# Employees_Salary_Prediction

## Project Overview
This project explores employee data and predicts salary using machine learning. It compares three regression models to evaluate their performance.

## Dataset 
The dataset was obtained from Kaggle and contains employee information such as age, experience, education level, department, job title, location, gender and salary.

## Tools used 
- Python
- Pandas
- Numpy
- Matplotlib
- scikit-learn

## Model Evaluation
The models were evaluated using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R2.
Linear Regression performed best on the test set, with the lowest MAE and RMSE and the highest R2 among the three models.
